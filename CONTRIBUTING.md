# Contributing

## Development principles

- Keep matching and message generation explainable and grounded in verified evidence.
- Do not add scraping, browser automation, or automated outreach.
- Keep secrets in environment variables and never commit `.env` files.
- Add focused backend, frontend, and end-to-end tests with each feature.

## Local checks

Run the commands in the README before opening a pull request. GitHub Actions
will run the backend and frontend checks on pull requests and pushes.
